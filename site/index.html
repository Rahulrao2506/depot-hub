Built for the first hours of an emergency

When towers are down or power is out, people near each other still need to talk. DEPOT keeps everything on one small local network.

Live chat channels

General, Medical, Supplies and Rescue, so urgent messages don't get buried.

File and photo sharing

Share maps, lists and photos up to 25 MB, then browse and search them in one library.

Voice notes

Record and send a message when typing is hard. Playback works in any browser.

SOS with a health card

Hold one button. Every phone gets a loud alert with blood group, allergies and contact. Responders tap "I'm coming".

Safety check-in

Mark yourself safe, in need of help or injured, so families and teams can see who is accounted for.

Network monitor

See who is online, which devices are connected, and the Pi's temperature, memory and storage.

Offline first-aid guide

Bleeding, CPR, burns, clean water, earthquake and flood steps, readable with no signal.

Spam guard

Flooding and repeated messages get escalating timeouts. SOS is never blocked.

How it works

Nothing to install on phones. The Pi does the work.

1

The Pi makes a Wi-Fi network

It broadcasts a network called "depot" and hands out addresses to phones that join.

2

Phones open the hub

The page opens automatically, or at 10.42.0.1. Pick a name and you're in.

3

Everything stays local

Messages and files are stored on the Pi's own card. No cloud, no accounts.

Set up your own hub

You need a Raspberry Pi with Wi-Fi and a microSD card with Raspberry Pi OS.

  1. Download the code and copy it to the Pi.
    git clone https://github.com/Rahulrao2506/depot-hub.git
cd depot-hub
  2. Run the setup script. It installs everything and starts the hub on boot.
    sudo bash pi/setup.sh
  3. Join the Wi-Fi named depot from any phone and open https://10.42.0.1. Accept the one-time certificate warning; this is what allows voice recording.
  4. Try it on a laptop first if you have no Pi yet.
    pip install flask
python server.py

Know the limits

  • SOS alerts people on the same Wi-Fi only. It does not contact emergency services, so call your local number if you have any mobile signal.
  • Everyone must be within range of the Pi's Wi-Fi.
  • Messages are not end-to-end encrypted, and names are not verified.
  • This page is only a showcase. The real hub runs on the Pi, not on this website.
